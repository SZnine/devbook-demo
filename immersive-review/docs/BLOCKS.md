# 内容、书籍、章节与引用 · 当前规则

更新：2026-10-17。用户可以先建层级直接写，也可以从随笔逐步组织自己的阅读。Markdown 是当前保存和渲染形式，不要求用户先上传完整文档。以下描述本轮实现，不作为不可调整的协议。

## 当前对象

| 对象 | 职责 |
| --- | --- |
| 随笔 `Note.kind = memo` | 独立的 Markdown、创建/修改时间、草稿与归档；可带 `source` 引用快照，出现在随笔流 |
| 正文 `Note.kind = document` | 书籍或章节内创建、自动保存的内容；不进入随笔流；从随笔加入时创建独立副本 |
| 原手册节 | 沿用稳定 id、标题、布局及 parts；原文只读 |
| 书籍 | 阅读站根 `Collection`；标题、摘要、有序内容引用、可选阅读别名、归档和删除状态；允许引言与章节 |
| 章节 | 被上级引用的 `Collection`；可同时包含摘要、正文与子章节 |
| 叶子引用 `Ref` | `note / section`；`note` 可指随笔或书籍正文，具体用途由 `Note.kind` 区分；记忆身份仍使用这一层 |
| 内容引用 `ContentRef` | 在叶子引用之外增加 `chapter`，让正文与子章节按顺序组织 |
| 引用来源 `MemoSource` | 保存来源位置、标题、路径、引用内容、可用前后文和采集时间；是快照，不是同步正文 |
| 删除记录 `DeletedContent` | 保存摘要或正文删除时的内容与所属位置，以便恢复；层级删除另用 `Collection.deletedAt` 标记 |
| 草稿 | 未保存内容、编辑目标及可选引用来源；不等同正式随笔 |
| 记忆条目 | 保留阅读事件并投影当前新鲜度，具体规则见 [DESIGN：自动阅读与记忆库](../DESIGN.md#自动阅读与记忆库) |

代码沿用 `Collection` 名称以兼容既有数据。书籍与章节由真实父引用判定，路径查询防止损坏循环；归档和删除不移除父引用，不将子章节误认成根书籍。`Note.kind` 对旧数据可缺省，新对象明确写入用途。上述是当前兼容方案，不冻结永久模型名称。

## 写作与组织

1. **先写或先建书。** 随笔入口保存独立随笔；阅读站先建书籍，再写引言或建立章节。阅读站新增内容保存为独立正文，不要求提前规划全部目录，也不自动成为随笔。
2. **从随笔加入。** 向书籍或章节放入随笔时，复制当时内容并生成新的正文 id。之后修改随笔或正文，互不覆盖。复制得到的正文不继承来源的阅读活动。
3. **兼容旧共享数据。** 原有 id、内容与历史先保留，不批量猜测旧 Note 的用途。首次在书籍内修改旧随笔或多个位置共用的正文时，为当前位置创建独立正文；保留旧对象及其学习记录，不伪造副本的学习历史。
4. **组成与移动章节。** 编排中多选条目按原顺序组成章节；展开到上级执行反向组织。移动、排序和归档改变组织关系，不增加阅读活动；禁止将章节移入自己或后代。独立为书籍或作为章节移入均保留 id 与下属层级。
5. **连续阅读。** 按顺序展开下级正文，编辑作用于对应正文；不把多个正文拼成新的存储文档。书籍内部复制暂保留来源关系，写入时按前述规则分离。

段落、列表、图片、引用与代码先作为 Markdown 内的格式元素。可组织单元是独立正文、原文节和章节；尚不是每个 Markdown 段落。存储边界不强制形成可见卡片，正文不重复显示工具栏。更细粒度先验证具体操作，不预先扩张块类型。

浮动组件工具条提供彩色图标与中文名称，插入或转换当前编辑范围。添加标题、代码或图片不创建新的正文身份、章节或学习记录。图片使用用户提供的有效链接，本轮不增加上传或资源后台。编辑器、快捷键与保存方式见 [DESIGN：创建与插入](../DESIGN.md#创建与插入) 和 [内容区与操作](../DESIGN.md#内容区与操作)。

## 删除与引用随笔

书籍、章节、摘要和正文提供右键删除。有选区时仅删除选区，交给该编辑器的撤销历史；无选区才执行整项删除。书籍或章节以 `deletedAt` 隐藏自身与下属内容，保留原有层级；摘要和正文保存删除快照，正文还保存原位置与阅读别名。回收站恢复时先恢复所属层级；恢复摘要不覆盖已有摘要，正文恢复保留删除时的内容。当前会话保留最多 100 个已提交删除的身份，Ctrl/⌘+Z 恢复一个对应对象，不覆盖其他修改；手动恢复会移除相应撤销项。归档与删除分开，当前不提供永久删除。统一归档入口支持随笔、书籍、章节的搜索和恢复。具体入口见 [DESIGN：删除与引用随笔](../DESIGN.md#删除与引用随笔)。

摘要或正文右键可以生成引用随笔；选中文本时以选段和可用的前后文作为背景。新随笔使用独立 id 和 Markdown，`source` 保存 `kind`、`collectionId`、可选 `ref`、`title`、`path`、`quote`、可选 `quoteFormat: 'markdown'`、可选 `before / after` 及 `capturedAt`。新引用保留 Markdown；代码选段补齐语言围栏。旧引用缺省为纯文本，只在能确定完整匹配未修改来源时借用其格式展示，不重写历史快照。选中不自动保存，用户确认随笔后才写入。来源后续变化不更新快照；来源删除也不删除随笔。随笔编辑不回写原文。

旧共享正文首次修改时仍创建独立的 document 身份；编辑器实例通过当前会话身份映射保持稳定，草稿转移到新身份，避免自动保存造成重建编辑器和丢失文本撤销历史。

新选段引用增加 `contextMarkdown` / `contextTitle`，保存最近小标题及其正文快照，结束于下一同级或上级标题，保留更低层级标题。无标题时保存当前正文；首标题前仅使用引言。用 Markdown AST 与实际选区位置定位，代码围栏和引用示例中的标题不参与外部小节切分；DOM 映射不将 Vditor 的 PRE 宿主视为代码块。原有 `before / after` 数据保留兼容，但界面不再呈现截断前后文。这个默认块边界用于引用上下文，不改变书籍正文的存储身份，也不自动切割文档。

## 原文与渲染

唯一训练手册继续来自 [manual.json](../src/manual-demo/manual.json)。`recall` 保留题目与答案关系，`reading` 保留正文；参考资料不决定用户必须采用同样层级。原文只读，编辑入口创建自己的独立副本，不覆盖材料，也不继承原文学习活动。

阅读站使用 Vditor，默认可编辑的即时呈现，支持 Markdown 输入与自动保存。源码模式只是同份正文的另一种表示，关闭源码仍可编辑。静态内容沿用 [Markdown、代码与媒体渲染](../src/content/README.md)。正文、编排和连读消费同一份正文，编排摘要不是另一个版本。

实际内容合并、自动分类、语义改写及实验、背景、评论等独立业务模块本轮未实现。助手的真实能力与写入限制统一以 [DESIGN：右侧 API 助手](../DESIGN.md#右侧-api-助手) 为准。

## 记忆与保存边界

记忆记录保留原有身份与活动。随笔及书籍正文沿用 `read-notebook`，原手册沿用其原文身份；书籍、章节和摘要不生成聚合保持率。自动阅读门槛、去重、版本、推荐系数及 AI 评分以 [DESIGN：自动阅读与记忆库](../DESIGN.md#自动阅读与记忆库) 为准。

`read-notebook-v1` 保存随笔、独立正文、层级、摘要、草稿和删除快照；记忆沿用原存储。旧扁平合集按根书籍保留，旧节内随笔与草稿仍只迁移一次，原数据库不删除，不做新旧双向同步。删除不擦除原学习事件；创建副本不复制来源学习事件。

正文自动保存失败时保留输入并提示；当前标签页的 `sessionStorage` 草稿与随笔的持久化主草稿分开，不等同跨设备同步或永久版本历史。统一撤销、版本历史、细粒度内容组织与协作保存仍待后续验证。本文说明规则，不替代浏览器验收结论。

具体交互、API 配置边界与视觉参照见 [DESIGN.md](../DESIGN.md)。
