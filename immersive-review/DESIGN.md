# 当前界面规则

保留 Craft 风格的侧栏、顶栏和工具岛。具体布局与行为先通过实际使用验证，再决定抽象；本文记录当前实现，不冻结后续架构。历史截图与研究不属于发布内容。

## 创建与插入

- 开始页显示真实内容和新建动作。先建书籍或写随笔，书籍是根，章节有上级；不依赖导入完整 Markdown。
- [Excalidraw](https://excalidraw.com/) 式浮动工具条不挤占左侧目录。彩色图标标识 Markdown 类型；`Ctrl+Alt+M` 显隐，空行 `/` 搜索。说明放在提示与设置中。
- 直接插入空结构，默认 H2、纯文本代码、2 列 × 2 行表格；占位不写入正文。选区切换格式作用于当前范围，可撤销，不产生额外空框。
- 代码、引用、列表、表格可通过“继续正文”或 `Ctrl/⌘+Enter` 退出；普通正文中该键保存，`Ctrl/⌘+Shift+Enter` 明确保存。输入法组合期间跳过快捷键。
- 默认是可直接编辑的即时呈现，“源码模式”只切换同份 Markdown 的表示，不称为预览；点击或双击不切换源码。

## 内容区与操作

[Craft 页面](https://support.craft.do/en/write-and-edit/blocks-and-pages)和[GitBook 页面结构](https://gitbook.com/docs/create-content/content-structure/page)提供直接参照：标题、摘要、正文共用连续表面；章节目录是紧凑链接行。卡片用于书架、随笔流与编排，不由存储单元决定外框。

当前适配尺寸：左侧轨道 244px、顶栏 56px；正文最大内容宽 736px；标题 32px、摘要 18px、正文 16px；章节目录行至少 44px。这些是项目值，不是参考产品规格。

摘要紧贴标题，不常驻“摘要”标签。书籍保留目录创建入口；没有子章节的章节不展示空目录。摘要不是随笔，也不计学习。正文自动保存，随笔显式保存。当前光标位于尾部空块时才显示输入提示，移到前文或失焦即隐藏。

从随笔加入书籍会创建独立正文副本，之后互不覆盖。旧共享内容首次写入时按当前位置分离身份，保留编辑器实例与撤销。编排允许多选、分组、移动、排序；连读按真实顺序展开，不创造新正文身份。组织参照 [Scrivener Corkboard](https://www.literatureandlatte.com/blog/organize-your-scrivener-project-with-the-corkboard) 和 [Scrivenings](https://www.literatureandlatte.com/blog/view-and-edit-multiple-documents-with-scrivenings)。

## 删除与引用随笔

右键文字简短：写随笔、复制、删除。有选区只删选区；无选区才删除整项，摘要与正文保存恢复快照。书籍、章节删除保留层级，回收站可恢复；归档有独立管理入口。`Ctrl/⌘+Z` 支持本会话整项删除，文本输入优先走编辑器撤销。参考 [Craft Trash](https://connect.craft.do/api-docs/space) 与 [Notion 恢复](https://www.notion.com/help/duplicate-delete-and-restore-content)。

引用随笔保存 Markdown 快照与所属小标题上下文，保留代码围栏；不回写原文，不自动采集整章。新选区覆盖旧候选。只有引用而没有个人正文的新草稿退出时清理；真实输入保留。引用边框点击后出现、移出后消失，重新移入不会自动恢复。引入正文有低权重标记，暗色保持可读。

## 自动阅读与记忆库

正文在前台可见、窗口聚焦且活跃时累计有效阅读。约 20–90 秒并达到正文覆盖要求后建立记录；后台、编辑、摘要、目录、编排不计。30 分钟内重复合并，同日不重复增加长期权重。新鲜度描述接触，不是记忆测验概率。

列表只留标题与固定刻度绿条：`原生评分 × (1 − 新鲜度)^遗忘权重`。不设阶段分类、推荐批次或自动换篇。学习事实、补记、撤销、手动评分放在详情；配置入口集中调节系数和 AI 评分。

AI 只在明确点击更新时对最近最多 20 项的章、节标题与简短正文摘录进行比较；不自动发送全文。相对排名映射到 0.15–1，单项 0.5，手动值优先；内容变化后旧 AI 评分不继续用于当前版本。

## 右侧 API 助手

直接对照 [Craft Assistant](https://support.craft.do/en/ai-assistant/using) 的单输入容器：附件在内部顶端，模型与风格在底栏。选区需勾选才附带，范围和回答风格使用紧凑菜单；实际上下文预览与历史覆盖显示，不推挤输入框。保持连续对话、停止、复制与失败重试，不替用户执行正文修改。

上下文三档：选区；小节标题及全文；再附章标题、小节目录与书名。上下文处理保留 Markdown 和重复文本的正确位置。风格四档通过指令提供，不保证不同模型完全相同。拖动左缘或键盘调整宽度，历史保存于当前浏览器。

## 导航、色彩与动效

参考资料右侧仅是本章目录，全书切章留在左侧。对照 [VitePress](https://vitepress.dev/guide/markdown) 的细竖线、当前节标记与无卡片链接；目录位于顶栏下方，不参与顶层网格。桌面至少 1240px 时固定预留 280px 右侧空间，开合不改变顶栏或正文几何；窄窗使用浮层，选择后收起，Esc 关闭。助手与目录互斥。

暗色参照 [Momos](https://momosz.com/) 的中性煤灰背景，避免整页蓝紫；图标颜色表达用途，正文保持中性。代码使用当前真实语法主题，明暗切换不重建编辑器。无依据的纹理、厚阴影和说明文字不用于填空。

控件动效参考 [Radix Collapsible](https://www.radix-ui.com/primitives/docs/components/collapsible)：树高度收合 220ms，悬停按下 100–130ms；支持反向连续操作，尊重减少动态效果。页面和正文切换不做快照或位移入场。导航标签不可误选，正文仍可选择。

验收沿完整路径：创建 → 输入与格式 → 源码切换 → 编排移动 → 连读 → 刷新；加查删除撤销、引用来源、旧数据分离、归档恢复、目录开合、助手菜单及保存失败。构建通过不等于全部交互情境验证完成。
